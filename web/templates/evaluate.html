Evaluate a plan

Upload a CSV with two columns — GEOID20 (the 12-character Census VTD identifier) and district (an integer) — one row per VTD in the state. The server joins to that state's VTD shapefile, dissolves to district polygons, and runs the same metric pipeline used in the case studies. You'll be redirected to a permanent shareable URL when it finishes.

For details on the metrics, see the methodology page. Adding a new state requires server-side data files; the dropdown below lists what's currently supported.
